# utils_render_template (Data Source)
Renders a template by replacing placeholders with values.

**Placeholder Syntax:** `@@VAR@@`

This syntax is designed to not conflict with:
- Argo Workflows: `{{inputs.parameters.*}}`
- Shell variables: `${VAR}`, `$(command)`
- Bash conditionals: `[[ ]]`
- Heredoc/redirection: `<<`, `>>`, `<>`
- Logical operators: `&&`, `||`
- Arithmetic: `(( ))`
- Windows batch files: `%%VAR%%`

All placeholders must have corresponding values or an error will be returned.
