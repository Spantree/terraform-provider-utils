# Spantree Utils Provider

The Spantree Utils provider offers utility functions including template rendering with custom placeholder syntax (`@@VAR@@`) that doesn't conflict with other templating systems like Argo Workflows, shell scripts, or Helm.

## Why This Provider?

When deploying resources like Argo Workflows, Kubernetes manifests, or shell scripts with Terraform, you often need to inject Terraform-managed values into templates that contain their own templating syntax.

**Common conflicts:**
- Argo Workflows use double-brace syntax for parameters
- Shell scripts use `${VAR}` and `$(command)` syntax
- Bash uses `[[ ]]`, `<<`, `>>`, operators
- Windows batch files use `%%VAR%%` syntax

**This provider solves it** by using `@@VAR@@` placeholders that don't conflict with any common templating system.

## Example Usage

```terraform
terraform {
  required_providers {
    utils = {
      source = "spantree/utils"
    }
  }
}

provider "utils" {}

# Basic example: Simple string interpolation
data "utils_render_template" "greeting" {
  template = "Hello @@NAME@@, welcome to @@PLACE@@!"

  values = {
    NAME  = "Alice"
    PLACE = "Wonderland"
  }
}

output "greeting" {
  value = data.utils_render_template.greeting.result
}

# Example: Configuration file with multiple variables
data "utils_render_template" "config" {
  template = <<-EOT
    server {
      host = "@@HOST@@"
      port = @@PORT@@
      environment = "@@ENV@@"

      database {
        connection_string = "@@DB_CONN@@"
      }
    }
  EOT

  values = {
    HOST    = "localhost"
    PORT    = "8080"
    ENV     = "production"
    DB_CONN = "postgresql://user:pass@db:5432/mydb"
  }
}

output "config" {
  value = data.utils_render_template.config.result
}

# Example: Script with shell variables preserved
data "utils_render_template" "script" {
  template = <<-EOT
    #!/bin/bash

    # Terraform-injected values
    NAMESPACE=@@NAMESPACE@@
    IMAGE_TAG=@@IMAGE_TAG@@

    # Shell variables that remain as-is
    echo "Namespace: $${NAMESPACE}"
    echo "Image tag: $(echo $IMAGE_TAG)"

    # Bash conditionals work fine
    if [[ -n "$NAMESPACE" ]]; then
      echo "Namespace is set"
    fi

    # Arithmetic expressions preserved
    count=$((1 + 2))
    echo "Count: $count"
  EOT

  values = {
    NAMESPACE = "production"
    IMAGE_TAG = "v1.2.3"
  }
}

output "script" {
  value = data.utils_render_template.script.result
}
```

## Use Cases

- **Argo Workflows**: Deploy WorkflowTemplates where Terraform manages infrastructure config and Argo manages runtime parameters
- **Kubernetes Manifests**: Inject environment-specific values while preserving scripts
- **Shell Scripts**: Generate scripts with Terraform values while preserving shell syntax
- **Configuration Files**: Create configs with Terraform-managed values
